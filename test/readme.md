# Bee Test Suite

## Convention
All test cases follow the pattern `TXXYY.bee`:
- **XX**: Level (01-99) denoting complexity tier.
- **YY**: Sequence number (01-99) within the level.

### Current Levels
- **Level 1**: Basic declarations, assignments, and expectation checks.
- **Level 2**: Basic IO and Hello World.

## Pipeline
Run tests using: `python test.py`
Results are logged in `/test/output`.
