## User-Locked Decisions (2026-09-12)

> The full normative backlog — including pending and deferred decisions —
> lives in `manual/DECISIONS.md`. The ratified subset is mirrored here for
> at-a-glance auditing.

- **Decision 1 – Indexing basis:** 1-based throughout source/parser/AST/evaluator/typechecker; IR lowering (`internal/compiler/`) is the only place 0-based appears. `$` = `len(c)-1`.
- **Decision 2 – Identity vs mutation:** `{is, is not}` are pointer-identity operators. `+=` / `-=` are pure lex-level shorthand for `+:=` / `-:=` (single AST node). `+is`/`-is` are NOT operators.
- **Decision 3 – Operator syntax canonicalization:** ⛔ **SUPERSEDED by Decision 12 (2026-09-13).** Historically: `≠` deprecated, canonical form `<>`; `==` / `!=` removed from lexer canonicalization. `≡` reserved for graphics congruence (per `solutions/013-geometric-congruence-operator.md`) — this reservation survives D12.
- **Decision 4 – Typechecker posture:** Postponed. Phase 5 deliverable reduced to symbol table + scope lookup; full type inference deferred until after Phase 6 IR codegen lowers 1-based indexing cleanly.
- **Decision 5 – Tutorial sync:** `bee-lang/tutorial/` is a versioned local directory that is the source of truth for the rendered HTML. It is mirrored one-way into `C:\Users\eluci\sage-code\scl\projects\bee` (the live SCL site content) via `sh run.sh sync` (backing script `scripts/sync_tutorial.py`). The symlink/junction model has been dropped in favour of an explicit mirror step.
- **Decision 6 – Curried rule signatures:** Rules MAY declare an optional *named-parameter slot* (`rule foo(*args)(sep: ", "  ∈  Str)`). Call sites apply the slot via a second parenthesised named-argument list (`print(a, b)(sep: " | ");`). The legacy `using` / `using:` postfix on `io_stmt` is deprecated; the lexer emits non-fatal `E0011` until Phase 7 audit task 7.2 hardens it to `E0009`. Named-arguments are order-independent; defaults fall through.
- **Decision 7 – Logic operator synonymy:** `is not` is one token (the lexer performs Maximal-Munch so `is` followed by space + `not` collapses into `IS_NOT`). Logic operators `and` / `or` / `xor` / `not` are accepted as synonyms for their Canonical Unicode equivalents (`∧` / `∨` / `⊕` / `¬`). The legacy Unicode `≠` and the ASCII `==` / `!=` are tolerated but emit non-fatal `E0010` deprecation warnings; they will be hardened to `E0009` once Phase 7 audit task 7.2 completes.
- **Decision 8 – Rule-call result destructuring:** 🟢 **Deferred** to Phase 8.4. Tuple-return rule grammar + multi-binding destructuring awaiting design. Test `test/debt/T0127-rule-call-result-binding.bee` parked. See `manual/DECISIONS.md` D8.
- **Decision 9 – Colon `:` is the pair-up operator (✅ ratified 2026-09-13)**: `:` is the canonical structural binding operator — key-to-value, parameter-to-type, identifier-to-literal, label-to-block-head — **without** type inference, ever. `=` is value equality (logic), `:=` is type-inferred assignment, `:` is structural pair-up and **requires** an explicit type context: in declarations the trailing `∈ Type` is mandatory, so `new a: 1, b: 2 ∈ Z;` is legal while bare `new a: 1;` is E0009 (use `:=` for inference). Cross-context grammar extension enables the parallel typed declaration (Issue 18). See `manual/DECISIONS.md` D9.
- **Decision 10 – Radical precedence (✅ ratified 2026-09-14)**: Power (`^`, `²`, `³`, `ⁿ`) binds tighter than radical (`√`, `²√`, `³√`, `ⁿ√`), which binds tighter than Mul/Div (`× ÷ / * %`) > Add/Sub (`+ -`) > Range (`.. …`) > Compare (`= …`) > Logic (`and or xor not`). Radicals are nullary **prefix** operators (never climbed as binary); the inner operand parses at the power rung so `³√ 2³ ≡ ³√(2³)` = `2`, while `(…)` always resolves first. Issue 17 resolved by the precedence-climbing refactor (PrefixExpression). Unary/binary NOT (`¬`/`!`) is governed by Decision 12. See `manual/DECISIONS.md` D10.
- **Decision 11 – Parallel colon-initialisation (✅ ratified 2026-09-14)**: parallel form `new (a, b) : (1, 2) ∈ Z;` parenthesises both the name list and the value list, each bound positionally and all sharing the trailing type qualifier (N = M enforced, the `:` pair-up of D9). The bare form `new a, b: 1, 2 ∈ Z;` is **rejected**; the repeated pair-up `new a: 1, b: 2 ∈ Z;` (D9) remains legal. See `manual/DECISIONS.md` D11.
- **Decision 14 – Uniform `done` terminator + `repeat` repurposed as jump (✅ ratified 2026-09-13)**: All control blocks (`cycle`, `for`, `if`, `match`, `start`, `with`, `trial`) terminate with `done [label];`. The `repeat` keyword is demoted from block terminator to inline jump statement (equivalent to `continue`). Optional label, optional scope: the colon is the sole prologue marker — `cycle [label] [:]`, so `cycle:` (colon, no label) opens an anonymous stable declaration prologue, while a bare label (`cycle name do`) is only a jump target. ~~`next` is retired; `repeat` absorbs its semantics.~~ (Reversed by Decision 15.) The `then` block becomes a post-loop epilogue executing once after loop exit. See `manual/DECISIONS.md` D14.
- **Decision 15 – `next` canonicalized as loop-jump keyword (✅ ratified 2026-09-13)**: `next [label] [if cond];` is the canonical continue-equivalent jump statement, reversing the D14 retirement of `next`. In a `while` cycle it jumps to the loop header and re-evaluates the condition; in a `for` cycle it advances the iterator to the next domain element and re-evaluates domain boundaries. Legacy `repeat` is a deprecated synonym: the lexer maps it to the `NEXT` token with a non-fatal `E0010` warning (hardening to `E0009` in Phase 7.2), so `@FROZEN` tests keep passing unmodified. `stop [label]` (exit past `done`) and `redo [label]` (restart current iteration without re-evaluating condition / advancing domain) are unchanged. See `manual/DECISIONS.md` D15.
- **Decision 12 – Inequality / logical-NOT operator refactoring (✅ ratified 2026-09-13)**: `¬` (U+00AC) is the canonical **binary value-inequality** operator; `!` is the canonical **unary logical NOT** (synonym: keyword `not`). Legacy forms `≠`, `!=`, `<>` all lex to the `NEQ` token with a non-fatal `E0010 deprecated-symbol … use '¬'` warning; `==` still lexes to `EQ` with an E0010 warning. Phase 7.2 hardens all four to `E0009`. `@` is the reference-of prefix: `@a = @b` ⟺ `a is b`; comparing `@a` against a plain value is always false. Supersedes Decision 3's canonical-form table. See `manual/DECISIONS.md` D12.
