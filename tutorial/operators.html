Bee Syntax

Bee is not a curly bracket language. Its syntax is inspired from Ada, Ruby, Fortran and Julia. We have created an imperative programming language with original front-end.

Operators

Bee operators are ASCII or Unicode symbols. One operator can be created using one or two characters. This is why Bee language is considered experimental, esoteric & disruptive.

Relation Operators

Relation operators are used to compare expressions.

symbol meaning
∈ check if element belong to collection
= equal { compare values or attributes}
¬ different { compare values or attributes}
≡ geometric congruence (same shape, any scale) — see Graphics
≈ approximating equal numbers, used with ± like: (x ≈ 4 ± 0.25)
> value is greater than: (2 > 1)
< value is less than: (1 < 2)
≥ greater than or equal to
≤ less than or equal to
÷ Exact divisor: 3 ÷ 15 = True

negation:

Operator: "!" can be used in combination with other operators:

 x ¬ y; -- equivalent to: !(x = y)
 x !∈ y; -- equivalent to: !(x ∈ y)
 x !≈ y; -- equivalent to: !(x ≈ y)
 x !~ y; -- equivalent to: !(x ~ y)

identity vs equality:

Operator "=" compares values. To compare references, use the reference-of operator "@" on both sides. A reference is never equal to a plain value.

 a = b;    -- value comparison: true when a and b hold the same value
 a ¬ b;    -- value inequality: true when a and b hold different values
 a is b;   -- pointer identity: true when a and b name the same allocation (same as @a = @b)
 @a = @b;  -- reference comparison: true only when a and b share one allocation
 @a ¬ @b;  -- reference inequality: true when a and b are distinct allocations
 @a = 1;   -- always false: @a is a reference, 1 is a constant value

CodeViolationMitigation / diagnostic action
E0101UTF8BomMarker: Unexpected UTF-8 BOM marker at source start.Strip the BOM from the source header.
E0102UnterminatedBlockComment: Block comment (+-) without a closing -+.Ensure closing -+ exists.
E0103InvalidEscapeSequence: Invalid escape sequence in a string literal.Use valid \n, \t, \uXXXX escapes.
E0104SingleLetterUppercaseIdentifier: Single-letter uppercase variable identifier.Use a lowercase start or a multi-letter type identifier.
